# 11 前端交互

本文把 `frontend-example/` 的交互与本设计对齐。整体布局可以保留：左侧故事列表，中间叙事流，右侧角色 / 世界 / IF 导图，外加设置弹窗。需要调整的是交互语义。

## 1. 输入区

| 现状 | 调整 |
|---|---|
| 一发送就"注入事件"，直接进入 JEV 推演 | 发送后先出现**裁定卡**（[01 §9](01-IF规则.md)），确认后才进入回合 |
| 事件标签：天气 / 时间跳跃 / 人物 / 势力 / 灾变 / 发现 / 自定义 | 去掉"时间跳跃"（叙事指令）和"发现"（指定了谁如何得知）。标签改为可选的 IF 类型提示，或者干脆去掉，由解析自动分类后显示在裁定卡上 |
| "自然推进"会发送"让故事自然推进一个时间单位" | 改名为"继续"，不发送任何事件文本，直接开始继续回合；时间是否推进由世界决定 |
| 随机事件骰子（含"时间快进 3 天"） | 改为"灵感"：由 T-inspire 生成 IF 形式的建议 |
| 只有一种动作 | 三种动作：IF（默认）、观测、继续 |

## 2. 裁定卡（新组件）

显示的字段见 [01 §9.2](01-IF规则.md)。交互要点：

- 类型、核心命题、时间锚点、作用范围、锁定等级可以直接修改。
- 回溯型必须选择消化策略。
- 冲突提示：对玩家隐藏的冲突只显示模糊的提示。
- 导演指令被拦下时，这里显示改写建议，并提示"改写后结果不再有保证"。

## 3. 推演卡（现在的 JevMsg）

| 现状 | 调整 |
|---|---|
| 步骤：解析事件语义 → 匹配世界规则 → 推演状态迁移 → 一致性校验 → 提交状态快照 | 改为真实的流程：解析 → 裁定 → 影响候选 → 掷骰 → 选场景 → 写作 → 回收 → 提交 |
| diffs 显示全部状态变化 | 按玩家视图过滤，隐藏的变化只显示"另有 N 项隐藏变化"；每一项标注来源（IF / 推演 / 正文） |
| 没有概率信息 | 显示可观察结果的概率和骰子，例如 `顾言察觉异常 58% · 🎲 0.41 → 成立`。内在结果（例如情感变化）默认模糊显示【待定】 |
| "一致性 0.93"（branchScore）语义不明 | 改为本回合的世界线偏移，或者删除 |
| "回滚"按钮 | 语义为回滚整个回合（[03 §6](03-事件与世界线.md)） |
| — | 调试模式下显示 Jev 模型版本、判定次数和耗时 |

## 4. 叙事消息

| 现状 | 调整 |
|---|---|
| 整段流式输出 | 按节拍放行：每个节拍通过检查后整段出现（可以做逐字动画） |
| 操作：复制 / 重新叙述 / 从此处分支 | 复制 / **重写**（沿用同一批骰子，换一种写法）/ **重掷**（换一批骰子，命运可能不同）/ 从此处分支 |
| choices 中有"让周望川说出……""让沈知遥把数据发到网上""时间快进 3 天" | 这些都是导演指令，去掉。改为"IF 灵感"（经过指令检测）和"观测建议" |
| — | 回溯改写之后，旧的正文以"旧世界残影"的样式显示（淡化或划线），不删除 |

## 5. 右侧面板

**角色**

- 每条信息都标注认知来源：已确认 / 某人所说 / 推测 / 你的 IF。
- 秘密和真实意图按玩家视图隐藏。示例中 ARGUS 的"当前目标：未知"就是正确的处理方式。
- "定型"的语义见 [10 §6](10-世界创建与导入.md)。
- 在面板上直接编辑角色，会生成一条状态型 IF，并经过裁定卡（P13）。

**世界**

- 变量与规则：显示编译出来的机制，例如"江水位每天上涨 0.4–1.2 m"。
- 新增"暗流"：显示趋势的模糊压力，不显示具体内容。

**IF 导图**

- 节点类型增加 swipe 和"未选之路"，默认折叠。
- "回溯"按钮改名为"回到此处"，避免与回溯型 IF 混淆。
- 显示世界线偏移。
- 节点详情中显示该节点的 IF，以及主要的结果翻转。

**故事线页**【后续】：显示各条故事线的阶段与压力。

## 6. 设置

| 分组 | 内容 |
|---|---|
| 提供商 · 大语言模型 | 按用途配置模型：**结构模型**（解析、候选、计划、回收）和**叙事模型**（正文）。至少两个槽位，可以指向同一个模型。提供商列表增加"OpenAI 兼容（Chat Completions）" |
| 提供商 · Jev | 地址、密钥、**固定版本号**（如 `jev-1.13.0`，默认不用 latest） |
| 提供商 · 生图 | 保持现状 |
| 引擎策略（全局默认值） | 一致性严格度、因果深度、叙事温度、重试上限、裁定卡自动确认 |
| 世界设置（移出全局设置，每个世界单独保存） | 随机种子、叙事风格、叙事视角、机制步长（原来的"时间粒度"）、导演风格、模式 |
| 存储 | 数据目录（每个世界一个 SQLite 文件），加可选的 WebDAV 同步。"本地文件夹 / SQLite"不再是二选一 |
| 调试 | 全知视图开关（供开发和创作使用） |

- "记录平行分支"改为"记录未选之路"。
- 密钥不再存进 localStorage：由 Rust 端存入系统钥匙串，前端只负责提交，不回显明文。
