## 标记约定

- 【待定】需要拍板。可以直接在原处写下决定，也可以写在下面的汇总表里。
- 【已确认】已经完成产品决策，正文按此实现。
- 【初始值】需要实测或用标注集校准的数值。
- 【待核实】写作时无法核对原始资料，实现前需要确认。
- 【实测】需要通过实验回答的问题。
- 【v1】第一版必须实现；【后续】预留，第一版不做。

## 术语表

| 术语 | 含义 |
|---|---|
| IF | 用户注入的权威反事实断言 |
| 观测 | 用户获取有限信息的动作，不改变世界 |
| 继续 | 不注入 IF，让世界自行推进一个场景 |
| 判定 | Jev 对一个问题的原始输出（概率、分布或评分） |
| 裁决 | 引擎按策略把判定变成结果（阈值、抽样、数值、加权选择） |
| 命运骰子 | 由世界种子和决策键派生出的随机数 |
| 决策键 | 跨世界线保持稳定的决策标识 |
| 裁定卡 | IF 解析结果的确认界面 |
| 推演卡 | 展示一个回合过程的卡片（原 JevMsg） |
| 事实 / 信念 / 声称 | Reality / Belief / Claim 三层 |
| 锁定等级 | L3 公理、L2 锚定、L1 惯性、L0 自由 |
| 预演 / 观察 / 提交 | Proposed / Observed / Committed 三个状态阶段 |
| 展示边界 | 节拍展示给玩家的那一刻：之前可以否决，之后只能解释 |
| 视图 | 为某个消费方编译的状态切片 |
| 任务 | 一次 agent 运行（一次新会话），由 Jev 主导的 host 控制 |
| 故事线 | 有生命周期的叙事线索 |
| 趋势 | 尚未提交、但持续累积压力的候选 |
| 设定条目 | 世界书中的静态设定文本 |
| 世界线 | 事件日志的一个分支（一个头指针） |
| 世界线偏移 | IF 的反事实代价；也用来度量两条世界线之间的差异 |
| 旧世界残影 | 回溯改写后，与新历史矛盾的已展示正文 |
